# 헥사 프리비즈

브라우저에서 바로 실행할 수 있는 경량 3D 프리비주얼라이제이션 도구입니다. 배우와 배경을 배치하고, 카메라 구도와 움직임을 키프레임으로 구성해 장면을 빠르게 미리 볼 수 있습니다.

## 주요 기능

- 육각형 기반 배우 캐릭터 생성 및 배치
- 머리, 몸통, 팔, 다리 관절과 자세 설정
- 배경 상자 추가, 크기·위치·회전 조절
- 24fps 키프레임 타임라인과 반복 재생
- 24mm, 35mm, 50mm, 85mm 렌즈 프리셋
- 돌리, 트럭, 팬, 크레인, 아크 카메라 무빙
- 16:9, 9:16, 1:1, 4:5, 2.39:1 화면 비율
- 장면 JSON 저장 및 불러오기
- 현재 프레임 PNG 및 영상 MP4/WebM 내보내기
- 실행 취소·다시 실행과 브라우저 로컬 자동 저장

## 실행 방법

별도의 빌드 과정은 필요하지 않습니다.

1. `hexa-previs.html`을 Chrome 또는 Edge에서 엽니다.
2. 배치 화면에서 배우와 배경을 구성합니다.
3. 타임라인에 키를 추가하고 카메라 화면에서 구도를 조절합니다.
4. **내보내기**에서 이미지 또는 영상을 생성합니다.

Three.js와 영상 멀티플렉서 라이브러리를 CDN에서 불러오므로 최초 실행 시 인터넷 연결이 필요합니다.

## 파일 구성

```text
.
├── hexa-previs.html  # UI, 3D 렌더링, 타임라인, 저장 및 내보내기
└── README.md
```

## 장면 데이터

장면은 JSON 파일로 저장됩니다. 배우, 배경 상자, 카메라 키, 재생 길이와 출력 설정이 포함되며, 앱에서 다시 불러와 편집할 수 있습니다.

## 브라우저 지원

최신 Chromium 계열 브라우저를 권장합니다. 영상 형식과 인코딩 속도는 브라우저의 WebCodecs 및 MediaRecorder 지원 여부에 따라 달라질 수 있습니다.
